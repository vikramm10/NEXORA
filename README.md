# NEXORA — Starter Project

This is the first visual foundation for NEXORA, a desktop-first AI-powered workspace.

## Files
- `index.html` — landing page
- `dashboard.html` — interactive dashboard shell
- `css/styles.css` — premium dark theme and responsive layouts
- `js/app.js` — simple navigation and interface interactions

## Important
This is a frontend prototype. Login, database, AI, payments, real analytics, and external integrations are NOT connected yet. Dashboard figures are illustrative sample content, not real business data.

## Preview on Android
1. Extract the ZIP file.
2. Open the `NEXORA` folder in Acode.
3. Open `index.html` and use Acode's preview option.
4. Tap "Explore workspace" to open `dashboard.html`.

## Publish with GitHub and Vercel
1. Create a new public GitHub repository named `NEXORA`.
2. Upload the files and folders from this project, keeping the folder structure.
3. Import the repository into Vercel.
4. Use the default static-site settings and deploy.

Do not upload passwords, API keys, private tokens, or personal data to GitHub.


## Motion and performance
- CSS-first entrance, hover, chart and ambient animations.
- Motion is disabled/reduced when the device requests reduced motion.
- Small-screen decorative motion is reduced.
- This is a frontend prototype; real-world performance must be tested after deployment on target devices and networks.
